# خطة التعلّم الأسبوعية – الموهبين الرياضية

نسخة نهائية خفيفة تعمل مباشرة على Node.js بدون مكتبات خارجية.

## المزايا
- رابط دخول واحد، بدون اسم مستخدم.
- كلمة المرور تحدد حساب المادة والصف تلقائيًا.
- الرابع الابتدائي والأول المتوسط مضافان افتراضيًا.
- خطة من الأحد إلى الخميس: عنوان الدرس، هدف التعلم، النشاط/الاستراتيجية، الواجب/المهمة.
- حفظ مسودة أو تسليم الخطة للمدير.
- لوحة مدير لمتابعة: تم التسليم / مسودة / لم يبدأ.
- عرض وتعديل أي خطة من حساب المدير.
- إضافة حسابات مواد جديدة وتعطيلها وتغيير كلمات مرورها.
- إعدادات اسم المدرسة، العام الدراسي، اسم المدير، وعنوان التقرير.
- قفل الأسبوع لمنع تعديل المعلمين بعد الاعتماد.
- تجميع خطط الأسبوع حسب الصف أو جميع الصفوف، ثم طباعة/حفظ PDF من المتصفح.
- تنزيل نسخة احتياطية JSON.
- حماية كلمات المرور بـ PBKDF2، جلسات HttpOnly، CSRF، وتحديد محاولات الدخول.

## التشغيل في VS Code
1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد المشروع في VS Code.
3. افتح Terminal داخل المجلد.
4. شغّل:

```bash
npm start
```

5. افتح:

```text
http://localhost:3000
```

## أول دخول للمدير
كلمة المرور المؤقتة:

```text
Admin@2026
```

سيجبرك النظام على تغييرها فور أول دخول.

## إعداد كلمات مرور المعلمين
بعد دخول المدير:
1. افتح **الحسابات**.
2. أمام كل مادة ضع كلمة مرور جديدة.
3. أرسل للمعلم رابط الموقع + كلمة مرور مادته فقط.

> لا ترسل كلمة مرور المدير لأي معلم.

## تصدير PDF
من لوحة المدير اختر الأسبوع والصف ثم اضغط **تجميع وتصدير PDF**. ستفتح النسخة الرسمية المجمعة. اضغط **طباعة / حفظ PDF** واختر `Save as PDF` أو `حفظ كملف PDF` من نافذة الطباعة.

## البيانات والنسخ الاحتياطي
بعد أول تشغيل ينشأ الملف:

```text
data/db.json
```

هذا الملف يحتوي الحسابات والخطط والإعدادات. احتفظ بنسخة احتياطية منه أو استخدم زر **تنزيل النسخة الاحتياطية JSON** من إعدادات المدير.

## النشر كرابط للمعلمين
التشغيل المحلي على VS Code لا يعطي رابطًا عامًا للمعلمين خارج جهازك. للنشر، ارفع المشروع إلى استضافة تدعم Node.js مع تخزين دائم للملف `data/db.json`، واضبط أمر التشغيل إلى:

```text
npm start
```

يفضل استخدام HTTPS عند النشر الفعلي.

## ملاحظة تقنية
النظام مصمم لمدرسة واحدة وحجم استخدام مدرسي صغير/متوسط. التخزين ملف JSON دائم وبسيط. إذا توسع الاستخدام إلى عدة مدارس أو عدد كبير جدًا من المستخدمين، يفضل نقل التخزين إلى PostgreSQL أو SQLite مُدار.
